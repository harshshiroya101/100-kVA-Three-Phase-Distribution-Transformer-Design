# Design of a 100 kVA, 3-Phase Transformer

## Overview

This project presents the dimensional design drawing of a **100 kVA, three-phase transformer** prepared for the Department of Electrical Engineering, Institute of Technology, Nirma University. The drawing includes transformer core and winding dimensions, tank dimensions, layout views, and a design-data table. All drawing dimensions are specified in millimetres, and the title block indicates a **1:5 scale**.
